# botan-order-counter

ぼたん セルフ会計

## 現在の仕様 V1.7
- 店内ドリンクメニューは飲み放題外の通常課金商品として会計へ加算
- 商品ボタンは税込価格表示
- 内部計算は税別価格を合算
- クーポンは税別小計から控除後、消費税を計算
- 消費税10%は端数切り捨てを標準設定
- 全商品の税別価格 / 税込表示価格を設定画面から変更可能
- 商品をお気に入り登録し「★お気に入り」から素早く注文可能
- 商品を1回タップ = 1注文として時系列記録
- 注文ごとに未到着 / 到着済みを管理
- 60分飲み放題タイマー
- 30分延長は席全員に自動適用
- 大人飲み放題 税別599円 / 人
- 大人お通し 税別300円 / 人
- 子供飲み放題 税別250円 / 人
- 大人30分延長 税別399円 / 人
- 子供30分延長 税別150円 / 人
- PWA / オフライン対応
- ファビコンを「肉」から、レシート＋チェック＋「ぼ」のセルフ会計デザインへ変更
- UIをダークブラウン / ゴールド基調にリファイン
