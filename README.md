# botan-order-counter

ぼたん注文・会計カウンター

## 現在の仕様 V1.5
- スマホで崩れていた60分飲み放題エリアを修正
- 歯応えポッポ（コリコリ）を税込437円へ修正
- 商品ボタンは税込価格表示
- 会計計算は「税別合計 → クーポン控除 → 消費税 → 税込合計」
- 消費税率と端数処理（四捨五入 / 切り捨て / 切り上げ）を設定可能
- 指定金額以上で使える割引クーポンを設定可能
- 全商品の税別価格 / 税込表示価格を設定画面から変更可能
- 商品をお気に入り登録し「★お気に入り」から素早く注文可能
- 商品を1回タップ = 1注文として時系列記録
- 注文ごとに未到着 / 到着済みを管理
- 60分飲み放題タイマー
- 30分延長は席全員に自動適用
- 大人飲み放題 税別599円（表示659円税込）/人
- 大人お通し 税別300円（表示330円税込）/人
- 子供飲み放題 税別250円（表示275円税込）/人
- 大人30分延長 税別399円（表示439円税込）/人
- 子供30分延長 税別150円（表示165円税込）/人
- ドリンク注文も時系列に記録
- ブラウザを閉じても端末内に設定・注文履歴を保存
- PWA / オフライン対応
