# botan-order-counter

ぼたん注文・会計カウンター

## 現在の仕様 V1.6
- 実際の会計レシートを基準に税別価格と税計算を補正
- 消費税10%は税別合計に対して最後に計算し、端数は切り捨て
- クーポンは税別小計から引いた後に消費税を計算
- 商品ボタンは税込価格表示
- 全商品の税別価格 / 税込表示価格を設定画面から変更可能
- 商品をお気に入り登録し「★お気に入り」から素早く注文可能
- 商品を1回タップ = 1注文として時系列記録
- 注文ごとに未到着 / 到着済みを管理
- 60分飲み放題タイマー
- 30分延長は席全員に自動適用
- ブラウザを閉じても端末内に設定・注文履歴を保存
- PWA / オフライン対応

## 実レシート確認済み税別価格

- 大人60分飲み放題 599円 / 人
- 子供60分飲み放題 250円 / 人
- 名物アカ 399円
- ぼたん幻のタン 499円
- 歯ごたえ◎ポッポ 399円
- たまごスープ 399円
- 白ご飯（中）299円

- 子供30分延長 150円 / 人
