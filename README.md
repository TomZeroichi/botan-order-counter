# ぼたん
## セルフ会計

## 現在の仕様 V1.8
- ヘッダー表記を「ぼたん / セルフ会計」の2段表示へ変更
- デザインをシンプルな黒・生成り・えんじ基調へ調整
- タイマーを「一時停止 → 再開」できるように変更
- 一時停止中は経過時間・残り時間も停止
- メイン画面に「会計リセット」を追加
- 会計リセットで注文履歴・タイマー・延長回数・会計金額を0へ戻す
- 人数・価格設定・クーポン設定・お気に入りは維持
- 店内ドリンクメニューは通常課金商品として会計へ加算
- 商品ボタンは税込価格表示
- 内部計算は税別価格を合算
- クーポンは税別小計から控除後、消費税を計算
- 消費税10%は端数切り捨てを標準設定
- 全商品の税別価格 / 税込表示価格を変更可能
- お気に入り登録対応
- 注文の時系列・未到着 / 到着済み管理
- 30分延長は席全員に自動適用
- PWA / オフライン対応
