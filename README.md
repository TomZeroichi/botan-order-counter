# botan-order-counter

ぼたん注文・会計カウンター

## 現在の仕様 V1.4
- 商品を1回タップ = 1注文として時系列記録
- 注文ごとに未到着 / 到着済みを管理
- 60分飲み放題タイマー
- 30分延長は席全員に自動適用
- 大人飲み放題 659円（税込）/人
- 大人お通し 330円（税込）/人
- 子供飲み放題 275円（税込）/人
- 大人30分延長 439円（税込）/人
- 子供30分延長 165円（税込）/人
- 料理代・基本料金・延長料金を自動合計
- ドリンク注文も時系列に記録
- ブラウザを閉じても端末内に注文履歴を保存
- PWA / オフライン対応
